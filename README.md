# ⚡ MOTION: AI Fitness Trainer

> Веб-приложение разработанное для **ADMIT HACKATHON**. Превращает обычную веб-камеру в интерактивный фитнес-контроллер прямо в браузере.

## 🎯 Выбранное направление
**Фитнес-тренер (Fitness AI Coach)**

## 🚀 Основной функционал
1. **Работа через обычную веб-камеру:** Работает мгновенно в браузере без установки программ или драйверов.
2. **3 Различных упражнения:**
   - **Приседания (Squats):** Отслеживание угла сгибания колен.
   - **Прыжки Jacks (Jumping Jacks):** Синхронный подъем рук и разведение ног.
   - **Подъем рук (Arms Overhead):** Фиксация полной амплитуды подъема рук.
3. **Визуализация распознавания:** Отрисовка скелета и ключевых суставов человека поверх видеопотока в реальном времени.
4. **ERROR MODE (Режим Ошибки):**
   - Автоматически выявляет неправильную технику (слишком сильный наклон спины при приседаниях, согнутые локти или недостаточная амплитуда прыжка).
   - Подсвечивает скелет красным цветом, выводит плавающий текстовый банер с подсказкой, воспроизводит предупреждающий звук и виброотклик.
5. **Мультимедиа & Геймификация:**
   - Звуковой отсчет перед стартом («3...2...1...»).
   - Различные звуковые эффекты для успешного повторения, ошибки и завершения тренировки (Web Audio API).
   - Фоновая музыка с переключателем.
   - Конфетти и подсчет сожженных калорий.

## 🛠️ Технологический стек
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Styling:** Tailwind CSS
- **Pose Detection:** MediaPipe Pose
- **Audio Engine:** Web Audio API (генерация звуков без зависимостей)
